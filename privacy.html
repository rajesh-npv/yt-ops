Privacy policy

Last updated 10 October 2026.

What YT Ops accesses

With the channel owner's permission through Google sign-in, YT Ops uses the YouTube Data API and YouTube Analytics API to upload videos, set titles, descriptions, thumbnails and publishing times, and read view, watch time and click statistics for the owner's own channels.

How the data is used and stored

The data is used only to publish the owner's videos and to measure how they perform. Sign-in tokens and statistics are stored on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API data

YT Ops's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube's own terms apply: YouTube Terms of Service, Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens and statistics are deleted within 7 days of revocation.

Contact

Questions go to the support email shown on the Google sign-in screen for YT Ops.
